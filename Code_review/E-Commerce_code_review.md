# 2025 유통데이터 활용 경진대회

### [최우수상_생성형AI 기반 오프라인 인터랙티브 쇼핑 어시스턴트]

[https://festa.kdlc.or.kr/circulation/data/68b694f69230dd20edbe6df7](https://festa.kdlc.or.kr/circulation/data/68b694f69230dd20edbe6df7)

### 배경

1. 오프라인 유통의 저성장
    - 23년 온라인 매출 비용이 오프라인 매출 추월해 매출의 절반 이상 차지
    - 22년 대비 23년 가장 저조한 성장률 보이는 업태는 대형마트
    - 22년 ~ 23년 retailer A,B 모두 전반적으로 감소하는 추세
2. 오프라인 유통채널의 식품 경쟁력 강화 필요성
    - 대형마트 오프라인 식품 매출 비중 67% → 전체 매출에서 식품 경쟁력이 가장 큰 영향력
    - 온라인 식품 매출 비중은 오프라인에 비해 비교적 적은 영향력
3. 오프라인 간편식 시장 현황
    - Retailer A, B 모두 지속적으로 간편식의 매출이 감소하는 추세
    - 식품산업통계정보의 20년 이후 오프라인 소매점에서 수집된 간편식류 POS 데이터를 활용해 연도별 매출액을 비교
    - 오프라인 소매점의 간편식 매출은 비교적 낮은 성장 보임

### Modeling

1. 구매 데이터 전처리
    - 결측치 제거
        - Master_category_full_name 값이 공백인 행 제거
        - Category 세분화
            - 가공식품>조미료>향신료>기타향신료
        - sales 열 생성
            - price와 sales_unit 곱해 sales 열을 새로 생성하여 매출 분석에 활용
2. 구매 데이터 시각화
    - 소매업체별 매출
        - A업체가 B업체에 비해 더 높은 매출을 기록하는 것으로 확인
        - 두 업체 모두 감소 추세
    - 즉석/편의식품 구매 데이터 분석
        - 즉석/편의식품 데이터 필터링 분석 결과, 40~44, 45~49세의 그룹에서 가장 많이 구매 확인
3. 추가 전처리

[사용한 데이터: 구매 영수증 데이터]

- 연관분석에 활용할 데이터 필터링
    - 고객 ID와 상품 설명 두가지 필요한 열에 대한 데이터 필터링
- 트랜잭션 데이터 생성
    - 고객 ID별로 구매한 상품 목록을 그룹화하여 트랜잭션 데이터 생성
- 원-핫 인코딩
    - 이진 행렬 형태로 변환하여 Apriori 알고리즘에 적합한 데이터 형식으로 바꿈
    - 각 열은 특정 상품이 해당 거래에서 구매되었는지 나타냄
1. Apriori 알고리즘을 활용한 연관 분석
    - 연관분석: 데이터 세트에서 변수들 간의 관계를 발견하는 방법
    - 장바구니 분석에 사용
    1. 최소 지원도(항목이 등장하는 비율)를 설정하여 자주 나타나는 항목 조합 추출
    2. 빈발 항목 집합 바탕으로 연관 규칙 생성
    3. 향상도 기준으로 규칙을 정렬하여, 무작위보다 더 자주 함께 구매되는 항목 조합을 우선적으로 확인
    4. 상품 추천이나 크로스셀링에 활용

### 차별점 및 배울점

- 데이터만 분석해서 데이터에 있는 정보만을 활용하는 것보다 최신 동향도 함께 파악해서 데이터를 더 넓게 파악하는 것이 중요
- 파생변수를 많이 생성하는 것이 아니라 꼭 필요한 파생변수만을 생성하는 것이 좋음
- 연관분석 방법 한 번도 활용안해봤는데 좋음 → 추천 시스템에 사용 가능
